# Support

This is a pre-release engineering project. The maintainers cannot promise a
response time, compatibility across every target, or production support.

- Use the repository's **Issues** tab for reproducible bugs and concrete
  feature or catalogue proposals. Choose the closest issue form and include the
  affected UETD/uef-gen version or commit.
- Use **Discussions** for usage questions and design conversations if the
  repository enables that feature. If Discussions are not enabled, search
  existing issues before opening a narrowly scoped question.
- Keep security reports private. Follow [SECURITY.md](SECURITY.md); do not post
  vulnerability details in Issues or Discussions.
- For target-specific behavior, provide exact part and board revision,
  toolchain, configuration, and reproducible steps. A host-only result is not
  hardware qualification.

Please do not use the issue tracker for private consulting, urgent field
support, or requests to debug hardware without a reproducible description.
