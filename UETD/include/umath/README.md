# UMATH numerical foundation

UMATH supplies allocation-conscious numerical types and algorithms used by UETD APIs.

## Contents

- <code>umath.h</code> is the umbrella for the supported core math APIs; <code>scalar.h</code>, <code>fixed.h</code>, <code>complex.h</code>, <code>constants.h</code>, <code>config.h</code>, and <code>status.h</code> define scalar configuration and shared numerical values.
- Subdirectories group vector and matrix algebra, geometry and Lie groups, derivatives, polynomials, signal processing, numerical methods, and probability. `numerical/` includes integration, splines and least squares; `probability/` includes distributions, deterministic random sampling and streaming statistics. Shared special functions live in `functions.h`.
- <code>internal_scalar_math.h</code> is an implementation helper. The later sparse CSR outline is colocated in `matrix/sparse_csr.h`; its manifest remains future-scoped and generation-blocked.

Each row describes one header. The file link opens its source; the overview summarizes its purpose, and key declarations list the principal API symbols.

Type names may be defined in the linked header or supplied by an included dependency. Status guide: **Public contract** describes an API surface but does not guarantee every target has an implementation; **Future / planned** is a design or backlog header; **Fail-closed scaffold** declares development operations that are not implemented; **Target-family scaffold** is not a part or board profile; **Internal helper** is not an application-facing include; **Build configuration** supplies compile-time selection and capability macros.
