# UCON public API placeholder

UCON is intended to be part of the UEF control and estimation library. UEF will
own its public types and algorithm assets; uef-gen will consume UEF's eventual
selection/assembly contract. The supplied specification still describes the
older generator-owned boundary, so reconcile that document before treating
this placeholder as a finalized API.

This directory currently contains documentation only. Add public UCON headers
here only when the algorithm designs and type contract are ready; do not copy
the transitional generator-side definitions as a shortcut.
